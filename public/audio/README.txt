Голос полицейского Мэда (квест Мэд и Фантомас)

Имена файлов с префиксом mad_:
  mad_card1_story.webm, mad_card1_prompt.webm, …
  mad_system_ok.webm, mad_system_wrong.webm

1. Скопируй ВСЕ файлы из этой папки audio/ в проект:
   public/audio/
2. npm run build && npm run deploy
3. На всех устройствах заиграют эти файлы.
4. На устройстве пользователь может перезаписать голос локально.

Старые пиратские файлы (card1_story.webm без префикса mad_) не подключаются.
